00 / ABOUT

MS student in Physics at Sogang University (CUPT Lab). I run X-ray reflectivity, diffraction, and coherent / Bragg diffraction experiments at synchrotron and XFEL facilities — and write the tooling that turns raw beamtime data into results.

Differentiable physics simulators, machine learning for inverse problems, reproducible analysis pipelines, and calculators that run on the machines actually sitting in the hutch.

02 / SOFTWARE

Tools I build.

ReflectoLearn

↗

A differentiable Abeles transfer-matrix simulator generates training curves on the fly — with Poisson noise, resolution smearing, and beam footprint — and a 1D CNN predicts film parameters from R(q). No dataset files needed.

PYTHON · PYTORCH · XRR

QoraFlow

↗

Data toolkit for time-resolved ultrafast experiments at X-ray free-electron lasers. Refactored from the lab's legacy XFEL_data system by @paulpeterkim.

PYTHON · HDF5 · XFEL

QoraPhase

↗

A JAX-native, composable phase-retrieval framework for CDI. Array in, reconstruction out — with origin, mask, and support conventions written into the API contract.

PYTHON · JAX · CDI

X-ray Toolkit

↗

Offline X-ray calculators and a beamtime logbook for the beamline control room. No server, zero runtime fetches, written in ES5 so it runs on the CentOS 7 default browser (Firefox 60 ESR) in the hutch.

WEB · ES5 · OFFLINE · EN/KO
